Microsoft Outlook 同步 Synology MailPlus 聯絡人＆行事曆

習慣使用 Outlook 收發郵件的使用者不在少數。當郵件伺服器轉換至 Synology MailPlus 後，Outlook 的聯絡人與行事曆需透過第三方工具同步。本篇介紹如何以 CalDav Synchronizer 搭配 Synology Contacts 與 Synology Calendar 完成設定。

CardDAV 用於同步聯絡人，CalDAV 用於同步行事曆。CalDav Synchronizer 為免費的 Outlook 增益集，可至 caldavsynchronizer.org 下載安裝。

01同步聯絡人CardDAV

1

開啟聯絡人的 CardDAV 設定Synology Contacts › 我的聯絡人 › ⋮ › CardDAV

開啟 Synology Contacts，於左側 我的聯絡人 旁按 ⋮，選擇 CardDAV。

2

複製 CardDAV 用戶端網址

於 CardDAV 帳號 視窗中，複製 CardDAV 用戶端 的網址，稍後貼入 Outlook。

3

於 Outlook 新增同步設定檔

安裝 CalDav Synchronizer 後，於 Outlook 功能區開啟 CalDav Synchronizer › Synchronization Profiles，在 Options 視窗按左上角的 ＋ 新增設定檔。

4

選擇 Generic CalDAV/CardDAV

於 Select Profile Type 選擇 Generic CalDAV/CardDAV，按 OK。

5

指定 Outlook 連絡人資料夾

Name 輸入設定檔名稱（範例 Contacts），於 Outlook folder 按 …，選擇 連絡人 資料夾。

6

輸入伺服器設定並測試

DAV URL貼上步驟 2 複製的 CardDAV 用戶端網址
UsernameDSM 帳號
PasswordDSM 密碼
Email address使用者的電子郵件地址

按 Test or discover settings 測試連線。

7

選擇要同步的通訊錄

於 Select Resource 視窗選擇要同步的通訊錄（範例 My Contacts，存取權限 rw），按 OK。

02同步行事曆CalDAV

1

開啟行事曆的 CalDAV 帳號設定Synology Calendar › 行事曆 › ▾ › CalDAV 帳號設定

開啟 Synology Calendar，於右側要同步的行事曆旁按 ▾，選擇 CalDAV 帳號設定。

2

複製行事曆網址

複製 Thunderbird 欄位的網址。此網址指向單一行事曆，適用於 CalDav Synchronizer。

3

新增行事曆設定檔並測試

依前述方式新增 Generic CalDAV/CardDAV 設定檔：

Name設定檔名稱，例如 Calendar
Outlook folder選擇 行事曆 資料夾
DAV URL貼上步驟 2 複製的行事曆網址
Username / PasswordDSM 帳號與密碼

按 Test or discover settings 測試連線，完成後按 OK 儲存。

同步設定說明

  • Synchronization mode：預設 Outlook ↔ Server (Two-Way) 雙向同步，於 Outlook 或 Synology 任一端修改皆會同步至另一端。
  • Synchronization interval：同步間隔，範例為 30 分鐘。
  • 若有多個行事曆或通訊錄需要同步，請分別新增設定檔。
建議：首次同步前，請先備份 Outlook 中既有的連絡人與行事曆資料，以免雙向同步時發生資料覆蓋。
