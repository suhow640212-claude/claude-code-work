00移轉前的準備

1取得 Google 服務金鑰

執行本篇步驟前，務必先完成服務金鑰的建立，請參考：Google Workspace to Synology MailPlus Server 無痛移轉工具－金鑰篇。

2調整帳號類型

Synology MailPlus 及 Synology Contacts 的帳號類型，須與目的地帳號類型相符。例如：目的地帳號為 DSM 本地使用者，則須確認 Synology MailPlus 及 Synology Contacts 目前的帳號類型亦為本地使用者。

3準備使用者清單（CSV）

建立一份使用者清單，列出 Google Workspace 帳號及其對應的目的地帳號：

  1. 使用 Microsoft Excel 或 OpenOffice 建立 CSV 檔案。
  2. 將每位使用者的資訊由左至右填入下列三欄。
  3. 儲存 CSV 檔案，例如命名為 userlist.csv。
Google Workspace 帳號來源郵件地址Google Workspace 密碼可留白MailPlus 帳號目的地帳號
yuki@example.com（留白）yuki
jack@example.com（留白）jack
selma@example.com（留白）selma
CSV 檔案內容（以逗號分隔）yuki@example.com,,yuki
jack@example.com,,jack
selma@example.com,,selma

Google Workspace 密碼：因已透過服務金鑰取得授權，此欄位可以留白。
MailPlus 帳號：本地使用者請輸入帳號名稱；LDAP 或網域使用者請輸入完整名稱（例如 domain\user1 或 user1@domain）。

重要：同一份清單上的使用者，須為同一種 DSM 帳號類型。

亦可下載 CSV 範本 進行編輯。

01郵件移轉步驟

1

建立轉移任務MailPlus Server › 伺服器管理 › 郵件移轉 › 新增

於 一般 頁籤填入以下資訊：

  • 任務名稱：輸入任務名稱。
  • 選擇伺服器類型：設為 Google Workspace。
  • Google Workspace 服務金鑰：上傳金鑰篇中下載的 JSON 服務金鑰。

亦可進一步指定 各時段移轉的帳號數，並勾選 訂定電子郵件移轉排程 設定任務時間。

2

匯入使用者清單

於 使用者帳號列表 頁籤按 匯入，選擇準備好的 CSV 檔案；再按 檢查，確認每個帳號的結果皆為 通過。

3

管理通知設定

於 通知設定 頁籤，可決定 MailPlus Server 是否寄送各帳號的轉移結果（成功或失敗），以及通知寄往來源帳號、對應的 MailPlus 帳號、系統管理員或指定的電子郵件帳號。

注意：須於 服務 › 通訊協定 中勾選啟用 SMTP，才能傳送通知訊息。
4

執行轉移任務伺服器管理 › 郵件移轉 › 選取任務 › 開始

MailPlus Server 使用增量轉移技術，可同步郵件及郵件匣的每一筆變動，因此使用者在轉移過程中仍可持續使用 Google Workspace 的郵件服務。

Google Workspace 持續收發→ 增量同步 →MailPlus Server

選取剛建立的任務，按上方工具列的 開始 即可執行。任務執行期間：

  • 按 詳細資訊（文件圖示）查看統計資料及日誌。
  • 若要修改設定，請先按 暫停 停止任務，修改完成後再按 開始 繼續執行。

依帳號及郵件數量而定，轉移任務可能持續數天甚至數週。轉移不會清除目的地帳號在 MailPlus Server 上的既有資料。

重要：為避免轉移發生錯誤，請勿於 MailPlus Server 更改 IMAP 或 POP3 設定，或於 Google Workspace 移動或刪除郵件。
5

切換至 MailPlus Server

正式從 Google Workspace 切換至 MailPlus Server 之前，須先執行轉移任務，確保所有使用者的郵件皆已完整轉移。轉移完成後，即可將郵件服務切換至 MailPlus Server，例如將網域的 MX 記錄指向 MailPlus Server。
