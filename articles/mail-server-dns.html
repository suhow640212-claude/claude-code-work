MAIL SERVER 基礎 1：DNS（Domain Name System）Server

架設郵件伺服器之前，必須先理解 DNS 的角色。本文說明網址與 IP 位址的關係，以及架設 Mail Server 前需要完成的準備：網域名稱、DNS 管理方式、固定 IP 與反向 DNS。

01網址是為了方便人類記憶

網址的每一段都有其意義。完整網域名稱（FQDN，Fully Qualified Domain Name）方便人類記憶，例如：

www網頁伺服器主機名稱
.
hongku虹谷資訊組織名稱
.
com商業組織類別
.
tw台灣國家

輸入 www.hongku.com.tw，即代表「位於台灣、一間商業公司的 WWW 伺服器」內的網頁內容。

02DNS 的角色：將網址轉換為 IP 位址

路由器只認得 IP 位址，不認得網址。因此在瀏覽器輸入網址時，用戶端電腦必須先向 DNS 伺服器查詢該網址所對應的 IP 位址，再以這個 IP 位址連接伺服器：

用戶端電腦

輸入
www.hongku.com.tw

→

DNS 伺服器

查詢結果
3.115.28.55

→

WWW 伺服器

以 IP 位址
連線並取得網頁

03架設 Mail Server 前的準備

為組織取一個網域名稱

可於 TWNIC 網域名稱查詢 確認想要的名稱是否已被註冊。

向網域服務商註冊網域

決定名稱後，可選擇 HiNet、PChome、GoDaddy 等網域管理商註冊您的網域。

決定網域的管理方式：代管或自管

代管 DNS由網域服務商的 DNS 解析網址，於服務商網站設定紀錄。
自管 DNS（本篇範例採用）由自己的 DNS 伺服器對外回應，本系列以 Synology DNS Server 建立郵件伺服器。

下圖為 PChome 網域管理設定為「自管 DNS」的範例，須填入自己 DNS 伺服器的 Name Server（NS）與 IP 位址：

申請固定 IP必要

架設 Mail Server 須向網路服務供應商申請固定 IP，網域名稱才能穩定指向郵件伺服器。

向電信業者申請反向 DNS必要

擁有網域並申請固定 IP 後，再向電信業者申請反向 DNS，例如中華電信的 HiNet 反解服務。

04反向 DNS 為何是必要設定

一般 DNS 查詢是由網址找 IP（正解）；反向 DNS 則是由 IP 反查網域名稱（反解）。收件端的郵件伺服器常以反向 DNS 驗證寄件來源。

正向 DNS（正解）

mail.您的網域→固定 IP

讓外部能透過網域名稱找到您的郵件伺服器。

反向 DNS（反解）

固定 IP→mail.您的網域

讓收件端確認郵件的來源 IP 位址，是否屬於通過驗證的網域名稱，常用於過濾垃圾郵件。

未設定反向 DNS 的影響

若郵件伺服器沒有設定反向 DNS，從您的郵件伺服器發送的郵件將會被大部分主要電子郵件供應商封鎖。

若無法設定反向 DNS，且郵件發送持續發生問題，請新增另一個 SMTP 伺服器以正常寄出郵件。建議使用知名的 SMTP 伺服器，以免寄送時被視為垃圾郵件而封鎖。
