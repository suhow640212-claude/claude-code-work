MAIL SERVER 基礎 2：以 Synology 建立 DNS

透過 Synology DNS Server 套件，可讓 Synology NAS 成為私人的網域名稱伺服器，提供網域名稱解析服務並全面控管網域的 DNS 記錄。本文介紹 Synology DNS Server 的基礎知識，並逐步完成轄區建立及資源記錄設定。

#MailPlus#DNS

01開始進行之前的準備

設定 DNS Server 前，請確認已完成下列事項：

安裝 DNS Server

登入 DSM，前往 套件中心 安裝並執行 Synology DNS Server 套件。

取得固定且公開的 IP 位址

若要提供公開的 DNS 服務，必須為 Synology NAS 取得固定 IP 位址，請向網際網路服務供應商申請固定 IP 網路。

註冊網域名稱

註冊方式已於前一單元〈Mail Server 基礎 1：DNS Server〉說明。

檢查防火牆及埠轉送設定

DNS 服務需要使用連接埠 53。若 Synology NAS 有使用防火牆，必須開啟此連接埠；若 NAS 透過路由器連接至網際網路，請設定埠轉送規則並開啟連接埠 53。

TCP 53UDP 53

向網域名稱供應商註冊裝置

向網域名稱供應商登記 Synology NAS 的 IP 位址及其他所需資訊，並將管理模式設定為「自管」，設定方式已於前一單元說明。

02建立 Master 轄區

Master 轄區儲存一或多個 DNS 網域的名稱資訊，並作為權威來源，提供轄區內所有 DNS 網域名稱的相關資訊。以下以網域名稱 hongku.tw 為例：

1

新增 Master 轄區DNS Server › 轄區管理 › 新增 › Master 轄區

開啟 DNS Server 並前往 轄區管理 頁籤，按 新增 並選擇 Master 轄區。

2

編輯轄區設定

網域類型選擇 正向網域，執行從網域名稱到 IP 位址的解析服務。
完整網域名稱輸入已註冊的網域名稱。
hongku.tw
主 DNS 伺服器輸入 ISP 提供的公開固定 IP 位址。訪客向 DNS Server 查詢上述網域名稱時，將被導向此 IP 位址。
114.34.160.46
序號格式選擇轄區記錄的序號格式：整數（0～4294967295）或 日期（YYYYMMDDNN，例如 2015043001）。
3

儲存設定

按 確定 儲存設定，新建立的 Master 轄區會出現在 轄區管理 頁籤中。

03資源記錄

建立 Master 轄區時，DNS Server 會自動建立三種資源記錄；其他記錄則可依需求自行新增。架設郵件伺服器時，MX 記錄為必要設定。

NS自動建立

名稱伺服器記錄

辨別您提供給註冊機構或 DNS 服務的網域名稱伺服器，讓查詢能傳送至您的 Synology NAS。

hongku.tw → dns1.hongku.tw
A自動建立

主機資源記錄

將網域名稱對應到一組 IP 位址。

dns1.hongku.tw → 114.34.160.46
SOA自動建立

起始授權記錄

記載此轄區的權威資訊，例如主要名稱伺服器與轄區序號。

A依需求新增

網站主機記錄（www）

建立名稱為 www 的 A 記錄，訪客輸入 www.hongku.tw 時即可造訪您的網站。

www.hongku.tw → 網站 IP 位址
CNAME依需求新增

別名記錄

將一個名稱指向另一個名稱，查詢別名時會被導向正式名稱。

別名 → www.hongku.tw
MX郵件伺服器必要

郵件交換記錄

指定負責接收此網域郵件的伺服器，外部寄給 @hongku.tw 的郵件才能正確送達。

hongku.tw → 5 hongku.tw

04建立資源記錄：新增 MX 記錄

1

開啟編輯資源記錄轄區管理 › 選擇轄區 › 編輯 › 資源記錄

選擇轄區，按 編輯 並選擇 資源記錄；於 編輯資源記錄 視窗中按 新增，選擇要新增的記錄類型。

2

輸入 MX 記錄資訊

名稱為資源記錄輸入名稱；若留白，其名稱與網域名稱相同。
TTL設定資源記錄存在於其他網域名稱伺服器快取中的時間。
3600
正規名稱輸入網域名稱，即完成郵件轉址設定。
hongku.tw

郵件伺服器所需的 A 記錄與 MX 記錄如下：

名稱種類TTL資訊
hongku.tw.A3600114.34.160.46
hongku.tw.MX36005 hongku.tw.
