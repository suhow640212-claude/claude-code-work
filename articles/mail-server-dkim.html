Mail Server 安全機制 · #DKIM

Mail Server 安全機制－DKIM（DomainKeys Identified Mail）防止電子郵件遭到假冒

採用 DomainKeys Identified Mail（DKIM）標準，有助於防止您網域的外寄郵件遭到假冒。部分電子郵件伺服器會要求寄件網域設定 DKIM，以免收到假冒的電子郵件。

#MailPlus#DKIM

01什麼是假冒電子郵件

「假冒電子郵件」是指變更電子郵件內容，讓郵件顯示非真實寄件來源的寄件者或寄件地址。假冒是在未經授權的情況下使用電子郵件，這種情形十分常見。

寄件者service@hongku.tw
主旨本月帳單通知
DKIM-Signature: d=hongku.tw; s=hongku; … 驗證通過
✕ 由第三方偽造寄出
寄件者service@hongku.tw
主旨帳戶異常，請立即登入驗證
無 DKIM 簽章，或簽章驗證失敗

02DKIM 的運作方式

DKIM 使用一組成對的金鑰：寄件伺服器以私鑰在所有外寄郵件的標頭加上加密簽章；收件伺服器則從寄件網域的 DNS 取得公鑰驗證簽章，確認郵件寄出後未遭人竄改。

私鑰（Private Key）
保存於 MailPlus Server

寄出郵件時，為郵件標頭加上 DKIM 簽章。私鑰不對外公開。

⇄成對金鑰
公鑰（Public Key）
發布於 DNS（TXT 記錄）

收件伺服器取得公鑰，驗證簽章並確認郵件未被竄改。

pass

傳送到使用者收件匣

quarantine

傳送至垃圾郵件匣

reject

拒絕傳送

03設定步驟

1

啟用 DKIM 簽署並產生公開金鑰MailPlus Server › 網域 › 編輯 › 進階設定

勾選 針對寄出的郵件啟動 DKIM 簽署，設定 DKIM 選取器前置字串（範例 hongku），按 產生公開金鑰，並將產生的金鑰複製下來。

2

啟用 DKIM 認證MailPlus Server › 安全性 › 認證

於 安全性 › 認證 勾選 DKIM，讓 MailPlus Server 對收到的郵件執行 DKIM 驗證。

3

於 DNS Server 新增 TXT 記錄DNS Server › 轄區管理 › 編輯 › 資源記錄 › 新增 › TXT

開啟 Synology DNS Server，於轄區管理編輯網域，新增一筆 TXT 記錄：

名稱hongku._domainkey格式為「選取器前置字串._domainkey」
TTL3600
資訊v=DKIM1; k=rsa; p=步驟 1 複製的公開金鑰

按 確定 儲存，即完成 DKIM 設定。

搭配 SPF 與 DMARC

SPF 驗證寄件來源 IP，DKIM 驗證郵件內容未遭竄改，兩者互補；再搭配 DMARC 指定驗證失敗時的處理方式，可完整防範網域遭到冒用。
