Synology MailPlus · Google Workspace 移轉 · 金鑰篇

Google Workspace to Synology MailPlus Server 無痛移轉工具－金鑰篇

Synology MailPlus Server 內建 5 個免費帳號授權，並提供移轉工具，協助您將 Google Workspace 的郵件、聯絡人與行事曆轉移至 MailPlus。轉移前須先向 Google 取得服務金鑰授權存取，本篇說明取得金鑰的完整步驟，依序操作即可完成。

00流程概覽

PART 1設定 Drive SDK API於 Google 管理控制台允許 Drive SDK 存取
→
PART 2建立服務金鑰並授權建立專案、啟用 API、產生 JSON 金鑰並委派全網域權限
→
NEXT執行轉移於 MailPlus 使用 JSON 金鑰執行轉移

01設定 Drive SDK API

1

登入 Google 管理控制台

使用欲轉移網域的管理員帳號登入 Google 管理控制台，按一下 應用程式。

2

前往 Google Workspace

應用程式 › Google Workspace。

3

按一下雲端硬碟與文件

於服務清單中按一下 雲端硬碟與文件。

4

按一下功能和應用程式

按一下 功能和應用程式。

5

允許 Drive SDK API 存取

點擊 雲端硬碟 SDK 區塊，勾選 允許使用者透過 Drive SDK API 存取 Google 雲端硬碟，按一下 儲存。

02建立服務金鑰

1

登入 Google API Console

以網域超級管理員身分登入 Google API Console（Google Cloud Platform）。

2

新增專案

按一下 選取專案，再按一下彈出視窗右上角的 新增專案。

3

輸入專案名稱

輸入專案名稱（範例 MailPlus），按一下 建立。

4

開啟專案

從右上角的 通知 開啟新建立的專案。

5

前往 API 程式庫

按一下導覽選單，前往 API 和服務 › 程式庫。

6

啟用所需 API

於搜尋欄搜尋並逐一啟用下方列出的 6 個 API。

1Admin SDK API2Google People API3Gmail API4Google Calendar API5Google Drive API6Tasks API
7

前往服務帳戶

按一下導覽選單，前往 IAM 與管理 › 服務帳戶。

8

建立服務帳戶

按一下 ＋ 建立服務帳戶。

9

輸入服務帳戶名稱

輸入服務帳戶名稱（範例 MailPlus），按一下 建立並繼續。

10

指定角色

角色選擇 Project › 擁有者，按一下 繼續。

11

完成建立

略過選填項目，按一下 完成。

12

管理金鑰

頁面會自動跳轉至服務帳戶清單。找到新建的帳戶，按一下 動作 下方的 ⋮，選擇 管理金鑰。

13

建立新的金鑰

按一下 新增金鑰 › 建立新的金鑰。

14

選擇 JSON 金鑰類型

於彈出視窗中選擇 JSON 作為金鑰類型，按一下 建立。

15

儲存金鑰檔案

金鑰檔案會自動下載至您的電腦，按一下 關閉。此檔案即為轉移時使用的服務金鑰，請妥善保存。

16

複製專屬 ID

前往 詳細資料 頁籤，將 專屬 ID 複製到記事本，稍後的步驟會使用。

17

前往 API 控制項

使用欲轉移網域的管理員帳號登入 Google 管理控制台，前往 安全性 › 存取權與資料控管 › API 控制項。

18

管理全網域委派設定

按一下頁面底部的 管理全網域委派設定。

19

新增用戶端 ID

按一下 新增。

20

授權用戶端 ID 與 OAuth 範圍

於彈出視窗輸入以下資訊，按一下 授權：
  • 用戶端 ID：貼上步驟 16 複製的專屬 ID。
  • OAuth 範圍：貼上下方的完整內容。
OAuth 範圍（請完整複製）https://www.googleapis.com/auth/admin.directory.user, https://www.googleapis.com/auth/admin.directory.domain.readonly, https://www.googleapis.com/auth/drive, https://mail.google.com, https://www.googleapis.com/auth/calendar, https://www.googleapis.com/auth/contacts, https://www.googleapis.com/auth/contacts.other.readonly, https://sites.google.com/feeds, https://www.googleapis.com/auth/tasks

完成後，即可使用步驟 15 下載至電腦的 JSON 金鑰，於 MailPlus 執行 Google Workspace 轉移。

注意事項

  • 建議為轉移任務建立專屬的專案，以確保隱私安全。
  • 此金鑰可用來存取網域中所有使用者的資料，請建立副本並妥善保管。
  • 專屬 ID 用於將全網域權限委派給服務帳戶。
  • MailPlus Server 使用 Google OAuth 2.0 認證，無須收集所有使用者的密碼即可轉移郵件；使用者清單中的來源帳號須為完整網域地址（FQDA），例如 user@example.com。
