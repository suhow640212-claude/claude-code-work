Synology MailPlus Server 垃圾信防制

Synology MailPlus Server 提供兩種垃圾信防制工具：SpamAssassin 與 MCP 資料保護。本篇針對這兩項工具，說明地址過濾、附件過濾、關鍵字評分與正規表達式規則的設定方式。

01SpamAssassin 設定

1

開啟自訂垃圾郵件過濾MailPlus Server › 安全性 › 防垃圾郵件 › 自訂垃圾郵件過濾

於 防垃圾郵件 頁籤按 自訂垃圾郵件過濾。

2

地址過濾

於 地址過濾 頁籤按 新增，輸入要過濾的寄件者電子郵件地址，並選擇 標記為垃圾郵件 或 標記為非垃圾郵件。地址可使用萬用字元，例如以 * 比對整個網域。

3

附件過濾

於 附件過濾 頁籤新增要阻擋的副檔名，附件過濾器會拒收含有這些檔案類型附件的郵件。

建議：可加入 .zip 或其他想阻擋的副檔名。目前夾帶 zip 檔的郵件，多數為網路釣魚郵件。
4

開啟進階設定MailPlus Server › 安全性 › 防垃圾郵件 › 進階設定

回到 防垃圾郵件 頁籤，按 進階設定。

5

開啟關鍵字過濾

於 一般 頁籤可設定 分數高於此數字則標記為垃圾郵件 的門檻（預設 5，標準），再按 關鍵字過濾。

6

新增關鍵字並給予評分

按 新增，選擇比對的 目標（例如內容含主旨），輸入要標記為垃圾的 關鍵字，並給予 1～10 分 的評分。郵件符合的所有條件分數會累加，總分高於門檻即標記為垃圾郵件。

02MCP 資料保護設定

1

開啟 MCP 規則管理MailPlus Server › 安全性 › 資料保護 › 管理 MCP 規則

勾選 啟動 MCP，設定 MCP 門檻分數（範例 100），並選擇超過門檻時的處理動作（例如 儲存至隔離區），再按 管理 MCP 規則。

2

分析垃圾信的特徵字詞

以下列垃圾信為例，信中反覆出現幾個具代表性的字詞，可作為篩選條件：

专业优势买单报关业务qq微信同号
3

以產生器建立正規表達式

可使用線上工具 正規表示式產生器，將上述字詞分別輸入欄位，頁面下方即會產生對應的正規表達式，將其複製下來：

產生的正規表達式（比對任一字詞）(?:专业优势|买单报关|业务qq|微信同号)
注意：產生器輸出的格式為 /(?:…)+/i。填入 MCP 規則時，請只貼上中間的 (?:专业优势|买单报关|业务qq|微信同号)，前後的斜線與旗標不需輸入。
4

新增 MCP 規則

於 MCP 規則中按 新增，輸入：

名稱自訂規則名稱，例如「報關」
目標標題, 內容（含主旨）
關係符合正規表達式
樣式(?:专业优势|买单报关|业务qq|微信同号)
分數依規則的可信度給分；設為 100 即單一規則符合就達到門檻

郵件符合的所有 MCP 規則分數會累加，總分達到 MCP 門檻分數（範例 100） 時即判定為垃圾郵件。

5

範例：篩選含中國手機號碼的郵件

若不想收到內文含有中國手機號碼的郵件，可新增一條 符合正規表達式 的規則，樣式如下：

中國手機號碼正規表達式^(0|86|17951)?(13[0-9]|15[012356789]|18[0-9]|14[57]|17[678])[0-9]{8}$
說明：^ 與 $ 代表整段文字必須「只有」手機號碼。若號碼夾雜在內文中，可移除開頭的 ^ 與結尾的 $：
(0|86|17951)?(13[0-9]|15[012356789]|18[0-9]|14[57]|17[678])[0-9]{8}
